
# The Scholar's Desk

**Academic Support & Guidance**

The Scholar's Desk is a premium academic support website designed to help students with research guidance, dissertation planning, thesis support, assignments, editing, and referencing.

## Features

- Premium navy blue, ivory, and gold design
- Responsive layout for desktop, tablet, and mobile
- Logo and brand text aligned horizontally in the navbar
- Academic service cards with individual service pages
- Pricing plans
- Contact form for student enquiries
- Professional typography and elegant styling

## Logo Setup

Place the logo image in:

`public/images/logo.png`

The navbar should display the logo on the left and the following brand text beside it:

**The Scholar's Desk**

ACADEMIC SUPPORT & GUIDANCE

Keep the logo and brand text horizontally aligned with a small gap, similar to a premium website navbar.

## Technologies

- Next.js
- TypeScript
- React
- CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Important

Update the service descriptions, prices, images, and contact details before publishing. Connect the contact form to a backend or email service to receive real enquiries.
